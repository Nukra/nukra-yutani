01

What it does

one script, seven surfaces

Every piece is generated from a single preset file, so switching colour changes all of them at once.

GNOME SHELL

Panel, overview, popups, dialogs and notifications restyled square and monochrome, with a scanline tile behind the top bar.

GDM GREETER

Wallpaper, fonts, banner and full chrome — patched into the shell's gresource, with a dnf hook so a GNOME update does not revert it.

TERMINAL

Full 16-colour ANSI ramp for Ptyxis, a boot-sequence banner on every new shell, and a typed-reveal effect on command output.

CRT OVERLAY

A GNOME extension compositing scanlines, vignette, phosphor glow, configurable flicker and a slow light sweep — over terminal windows only.

TYPE

Silkscreen for labels, Share Tech Mono for body, VT323 for entry fields. Installed to the user, and system-wide for the greeter.

REVERSIBLE

uninstall and gdm-restore put every file back, including the gresource, byte-for-byte from a stored pristine copy.

02

Presets

nine shipped · ls colours per preset

Each preset is four values — background, dim, foreground, hot — expanded into a 16-colour ANSI ramp. Below: the greeter prompt and a terminal, in every palette.

03

Candidate directions

ten · not shipped

Ten complete directions rather than ten palettes: each one sets its own type pairing, border language, panel furniture, scanline weight and density, drawn from a different corner of the fiction. Every card shows the same four surfaces — top bar, greeter, session, listing — so the differences are the design, not the content. Contrast is measured against the same floors the shipped nine hold to.

04

Desktop

drawn, not photographed

A schematic of the session: top bar furniture, a terminal, and the quick-settings popup. The bar sits at 52px and carries live gauges — CPU, memory, network, temperature, load, uptime — each with a sparkline of the last four minutes and a click-through detail panel, all sampled from /proc every two seconds. Percentage metrics share a fixed axis; network throughput has no ceiling, so it scales against the largest sample in view. Rendered from the same preset values the installer writes, so it tracks the palette rather than a screenshot.

05

Apps & icons

files · settings · 63 icon names

GTK apps follow the preset too. install writes gtk.css for GTK3 and GTK4, so Files and Settings pick up the palette, the square controls, and the uppercase header bars — pass --no-gtk to leave them on stock Adwaita. The icon set is drawn to the same rules as the wallpaper: 1.4px strokes, mitred corners, three colours per glyph. Anything it does not cover falls through to Adwaita.

06

Commands

./ptai-theme <command>

The greeter commands need root; everything else runs as you.

install [PRESET]

Install everything: shell theme, GTK app colours, icon set, terminal palette, fonts, wallpaper, banner, CRT extension.

reload

Re-render everything from the working copy and re-import the extension in place. Picks up edits to the shell CSS, extension JS, icons and GTK sheet without a logout — the iteration loop while you are changing the theme.

install --no-gtk --no-icons

Shell and terminal only. Leaves GTK apps and icons on Fedora stock.

set PRESET

Switch colour without reinstalling. Regenerates every generated file from the preset.

list

Show available presets.

status

Report what is installed, which preset is active, and the state of the CRT overlay and greeter.

crt subtle | standard | heavy | off

Effect intensity. crt terminal | screen sets whether the overlay covers terminal windows or the whole session.

sudo … gdm [PRESET]

Theme the login screen: dconf settings, system fonts, and the gresource chrome patch.

sudo … gdm-doctor

Report every link in the greeter chain and name the one that failed.

sudo … gdm-edit

Edit the live greeter CSS and re-patch on save. gdm-reload re-patches, gdm-preview opens a nested greeter.

ptai-type off | slow | fast

In-shell control of the typed-reveal effect. raw <cmd> bypasses it, crt <cmd> forces it.

uninstall

Remove everything. As root it also restores the stock greeter.

Download

fedora 44 · gnome 47–50

No build step. Clone or unzip, run the script.

CLONE

Best option — git pull picks up changes and re-applying is one command.

git clone https://github.com/nukra/nukra-yutani
cd nukra-yutani
./ptai-theme install green

ARCHIVE

Grab the latest tag from the releases page, unpack anywhere, run in place.

tar xf ptai-theme.tar.gz
cd ptai-theme
./ptai-theme install ice

Releases

LOGIN SCREEN

Separate step, needs root and glib2-devel. Restarting GDM ends your session.

sudo dnf install glib2 glib2-devel
sudo ./ptai-theme gdm green
sudo systemctl restart gdm
